StudyMate AI - Clean HTML/CSS/JavaScript Frontend

This version intentionally contains NO demo subjects, assignments, attendance records,
study plans, deadlines, or academic profile information.

The user logs in/registers first and then sees an empty dashboard.
They add their own:
- profile information
- subjects
- attendance
- tasks/deadlines
- planner preferences

Files:
index.html
style.css
script.js

Run:
Double-click index.html.
No Node.js, npm, React, or backend is required.

Important:
Login/register is frontend demo-only. Real authentication and AI API integration
can be connected by a backend team later.
