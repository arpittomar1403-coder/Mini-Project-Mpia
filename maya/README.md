# Maya (HTML + CSS + JavaScript)

Open `index.html` in a browser (double-click) — or use VS Code "Live Server".
Needs internet once to load Chart.js from a CDN. Register an account to start (demo data is preloaded).

Files
- js/storage.js  localStorage + date helpers
- js/data.js     demo data
- js/planner.js  priority score + study plan generator
- js/ai.js       keyword-based AI (replace askAI() with a real LLM call later)
- js/app.js      pages, routing, UI
- css/style.css  styles (light/dark theme)
